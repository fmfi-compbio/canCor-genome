# Assemblies and proteins used

* `canCor3.fa`: assembly of the *Insectozyma corydali* genome
* `canVerA1.fa`: assembly of the *Insectozyma verbasci* genome, previously published in [Brejová et al., 2023](https://doi.org/10.1128/mra.00005-23)
* `canVer-prot.fa`: protein sequences for the *Insectozyma verbasci* genome
